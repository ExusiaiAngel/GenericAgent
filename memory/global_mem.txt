## Task Runner — Stable Rules (2026-06-09)

- `agentmain.py --task <abs_path> --once` — background execution via internal Popen
- `agentmain.py --task <abs_path> --nobg --once` — foreground debug execution
- **SECURITY:** Write long/sensitive prompts to `task_dir/input.txt`; `--input` is ONLY for <=200 chars non-sensitive one-off debug
- Completion signaled by `done.json` with `status` + `exit_code`
- Failure diagnosis via `stderr.log`, `stdout.log`, and `done.json['error']`
- Use `memory/task_watchdog.py <task_dir> --json` to supervise real task dirs; verified on live `agentmain.py` with `pid_matches_agent=true`
- Default supervisor gate for background `--task`: formal watchdog `state=completed` and `exit_code=0`; then verify requested artifacts by absolute path
- Stale PID detection via `/proc/<pid>/cmdline` (Linux) or `/proc/<pid>/cmdline` (Linux)
- Path resolution: absolute as-is, relative names under `temp/`
- Requested deliverables must be written with absolute sandbox paths; relative artifact paths may land in `temp/` and fail acceptance
- Never use bare shell `&` or `nohup`; never use unconditional `killall`
